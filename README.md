# Podcast Generator

Application auto-hebergee de generation de podcasts en francais, orientee cout minimum, avec:

- gestion UI des categories et flux RSS
- composition multi-categories ponderee
- filtrage de fraicheur 48h
- duree cible configurable
- garde-fous budget/tokens pour API economique
- mode audio local ou cloud, avec sortie MP3 telechargeable depuis la vue du script
